# 🍅 Market Price Trend Analysis — Maharashtra Tomato Markets

A data analysis project studying tomato price behaviour across **6 major APMC markets in Maharashtra** 
from **January 2025 to August 2026** — covering 20 months of daily arrival and price data.

---

## 📌 Project Overview

| Detail | Info |
|--------|------|
| Commodity | Tomato |
| State | Maharashtra |
| Markets | 6 APMC markets (Mumbai, Pune, Pune Manjri, Nasik, Pimpalgaon, Nagpur) |
| Period | Jan 2025 – Aug 2026 |
| Records | 3,093 |
| Source | Agmarknet (Government of India) |

---

## 🗂️ Project Structure

tomato-market-analysis/
├── data/ → Raw dataset (CSV)
├── notebooks/ → Python analysis scripts
├── charts/ → Generated visualizations
├── report/ → Written findings and insights
└── webpage/ → Interactive showcase website

## 🔍 What We Analysed

- Price trend across 20 months (all 6 markets)
- Seasonal patterns (monthly and quarterly)
- Market-to-market price comparison
- Supply vs. price relationship
- Price volatility by market
- Year-over-year comparison (2025 vs 2026)
- Extreme price events and anomalies
